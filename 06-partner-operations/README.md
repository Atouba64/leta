# Partner operations — handbook index

End-to-end workflows for **fulfillment partners** (MSPs, OEMs, national field networks like Barrister-class orgs, enterprise IT departments). Leta is **Tier 3 smart hands** in a **GUS** chain; partners keep the customer story.

**Two-person company rule:** Prefer **free tiers**, outsource payments/KYC/video to specialists, automate only what saves phone time.
