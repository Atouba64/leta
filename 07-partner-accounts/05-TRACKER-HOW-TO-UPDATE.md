# How to update the partner & platform tracker

## One file to edit

**Edit this file only:**

[`data/partner-platform-tracker.json`](../../data/partner-platform-tracker.json)

Everything on [leta.repair/ops-tracker.html](https://leta.repair/ops-tracker.html) comes from that JSON:

| Section | What you can change |
|---------|---------------------|
| `config.pin` | Ops page PIN (plain text in repo only) |
| `config.page` | Eyebrow, title, deck copy |
| `config.gate` | PIN screen title and subtitle |
| `config.bannerEditLink` / `bannerHowToLink` | Banner links |
| `meta.lastUpdated` | “Last updated” date in the table banner |
| `statusDefinitions` / `categoryDefinitions` | Filter labels |
| `letaServices` | Service tags (reference list) |
| `entries[]` | Every platform and partner row |

After editing, sync to the website folder:

```bash
node scripts/sync-partner-tracker.js
```

That writes `website/ops-tracker-data.json` (deploy copy — PIN is stored as hash only).

Push both files to `main`. Netlify runs the sync command on deploy automatically.

## Local preview

```bash
# 1. Edit data/partner-platform-tracker.json
# 2. Sync
node scripts/sync-partner-tracker.js

# 3. Serve website/

# Open http://localhost:8080/ops-tracker.html — use config.pin
```

## Entry fields (each item in `entries`)

| Field | Example |
|-------|---------|
| `status` | `not_started` · `in_progress` · `applied` · `invite_pending` · `approved` · `active` · `rejected` |
| `statusDetail` | Human-readable sub-status |
| `dateStarted` | `2026-06-16` |
| `dateApplied` | Application submit date |
| `dateUpdated` | Always set when you change anything |
| `coiUploaded` | `true` / `false` |
| `owner` | Who owns this row |
| `notes` | Blockers, next steps |
| `outreachStage` | Partners only: `research` → `production` |

## Add a new platform or partner

Add an object to the `entries` array in `data/partner-platform-tracker.json`, then run sync.

```json
{
  "id": "unique-slug",
  "kind": "platform",
  "name": "Display Name",
  "category": "marketplace",
  "registrationUrl": "https://...",
  "registrationType": "self_serve",
  "georgiaRelevant": true,
  "letaServices": ["break_fix", "networking"],
  "status": "not_started",
  "statusDetail": "",
  "dateStarted": null,
  "dateApplied": null,
  "dateUpdated": "2026-06-16",
  "coiUploaded": false,
  "owner": "",
  "priority": null,
  "notes": ""
}
```

For named partners, set `"kind": "partner"` and optional `"repoFolder": "barrister-global-services"`.
