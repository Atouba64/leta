# Georgia wedge pilot — proposal outline (Barrister)

Share **after** Enver (or decision-maker) shows interest — not on cold open.

## Pilot summary

| Item | Proposal |
|------|----------|
| **Duration** | 4–6 weeks |
| **Volume** | 5–10 work orders (scale to 25 if KPIs hit) |
| **Geography** | Counties Barrister names (suggest: metro Atlanta + 1 secondary + 1 rural test) |
| **Ticket format** | Barrister / partner **WO #** on every Leta ticket (GUS preserved) |
| **Comms** | Partner dispatch uses **Leta portal/thread** for status; phone only for exceptions |
| **Rates** | Agree **flat or hourly** band per SKU before dispatch — locked at tech accept |

## KPIs (report weekly)

| KPI | Pilot target |
|-----|----------------|
| Partner **status calls** per WO | &lt; 0.2 (goal: &lt;1 per 5 WOs) |
| On-time arrival (GPS / en route) | ≥ 90% |
| First-time fix | ≥ 80% |
| Digital close-out (photos + sign-off) | 100% |
| Tech payout (Leta) | ≤ 48h after approve |

## What Barrister provides

- Named **pilot owner** (dispatcher)  
- Sample **rate card** or historical SKU examples  
- **POC / access rules** template  
- Permission to use aggregated pilot results in Leta marketing (negotiable)

## What Leta provides

- Partner portal access (or mobile **Partner dispatch** role)  
- Georgia bench (1099 techs vetted via onboarding)  
- Weekly **CSV + summary** email  
- Ops escalation phone (Leta) for P1 only  

## Commercial (starter — customize)

- **Platform fee** or **markup on pass-through labor** — pick one model before legal  
- No exclusivity in pilot  
- Either party can stop with **48h notice** on new WOs
