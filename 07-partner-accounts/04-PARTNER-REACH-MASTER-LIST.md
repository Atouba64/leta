## Create your Google Doc / Sheet (free)

1. Open [Google Sheets](https://sheets.google.com) → **Blank spreadsheet** (recommended for sorting/filtering).
2. **File → Import → Upload** → select this file’s table below as CSV, **or** copy the table from section **Master outreach table**.
3. Name the file: **`Leta — Partner reach tracker`**.
4. Add columns from [`crm-tracking-fields.md`](./partners-reach/crm-tracking-fields.md): contact name, phone, email, last touch, next step.
5. Pin the Sheet in your browser; share edit access only with Leta operators.

**Optional Google Doc** for narrative notes: create a Doc and link each partner row to its repo folder (`07-partner-accounts/<slug>/`).
