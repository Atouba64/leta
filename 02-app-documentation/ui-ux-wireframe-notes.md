# UI / UX wireframe notes — Leta

Scratchpad for flows and screens before high-fidelity design. Aligns to the **Leta** stakeholder model (customer, field tech, remote tech, partner).

## Design north stars

- **Clarity over cleverness:** ETAs, costs, and next steps visible without hunting.  
- **Field-first ergonomics:** large tap targets, offline-tolerant flows where possible, glare-friendly contrast.  
- **Trust surfaces:** who is coming, from which org, what data is shared during escalation.

## Customer portal (web + mobile web)

**Key screens**

1. **Home / request** — issue type, asset, urgency, address, consent checkboxes.  
2. **Estimate** — rate card breakdown + SLA window selection.  
3. **Live job** — map strip + timeline + contact/support.  
4. **Completion** — signature pad, receipt, rating.

**UX details**

- Skeleton states while matching; honest messaging if **no tech available** in radius.  
- Prominent **cancel / reschedule** with fee disclosure.

## Field tech app (mobile)

**Key screens**

1. **Onboarding & credentials**  
2. **Active toggle + map** of self vs offers  
3. **Offer card** — pay, distance, SLA, tools, partner brand marks  
4. **Active job** — checklist, media capture, customer contact policy  
5. **Escalate** — one-tap into session prep (camera/mic permissions)  
6. **Earnings & payouts**

**UX details**

- **Accept** requires explicit gesture to prevent pocket-accepts.  
- **Battery / data** awareness: compress uploads, resume interrupted uploads.

## Remote tech dashboard (web)

**Key screens**

1. **Queue** — filters: skill, SLA breach risk, geography  
2. **Session workspace** — video primary, ticket context sidebar, quick macros  
3. **Post-session** — resolution codes, handoff notes

**UX details**

- **Session join SLA** metric for remote team performance.  
- Clear **recording indicator** and **consent** capture where required.

## Partner dashboard (hybrid tier)

Per operational model: partner visibility into **agent locations**, **photos**, **signatures**.

**UX guardrails**

- Role-based views: dispatcher vs exec vs finance.  
- **PII firewall:** hide customer contact where contract says Leta is white-label.

## Accessibility & i18n

- WCAG-minded components from the start (contrast, focus order).  
- English-first copy; structure strings for localization later.
