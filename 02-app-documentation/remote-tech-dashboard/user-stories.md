# Remote technician (“Overwatch”) dashboard — user stories (Leta)

Audience: **remote technicians** who backstop field techs on complex work.

## Epic: Queue and presence

- **As a remote tech**, I want to see a **live queue** of in-progress jobs eligible for escalation so that I can prioritize critical sites.  
- **As a remote tech**, I want to set **available / busy** status so that dispatch rules do not route sessions to me when I am unavailable.

## Epic: Join and collaborate

- **As a remote tech**, when a field tech hits **Escalate**, I want to **accept** the session and join **video/audio** with minimal friction so that time-to-assist is low.  
- **As a remote tech**, I want **screen or camera sharing controls** appropriate to the job (subject to consent and policy) so that I can diagnose effectively.  
- **As a remote tech**, I want a **shared timeline** of ticket events (photos, errors, config notes) so that I do not repeat questions.

## Epic: Quality and outcomes

- **As a remote tech**, I want to **annotate** recommended next steps and mark whether the issue was **resolved** or needs **follow-up** so that metrics reflect reality.  
- **As a remote tech**, I want **post-session summary** auto-attached to the ticket for partner QA.

## Epic: Safety and compliance

- **As a remote tech**, I want **recording and retention** rules surfaced up front so that I stay within policy and law.  
- **As a remote tech**, I want **PII minimization** (only what the job requires) so that customer trust is preserved.

## Non-goals (initial)

- Becoming a full video conferencing product for generic meetings—stay **ticket-bound**.
