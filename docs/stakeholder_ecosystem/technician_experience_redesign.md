# Technician experience redesign

Technological infrastructure is useless if the platform alienates the humans executing physical labor.

| Incumbent pattern | Leta response |
|-------------------|---------------|
| Field Nation 10% platform tax | No punitive platform tax on payout; rate locked at accept |
| Spencer last-minute cancels | Mobilization smart-contract payout when fault is logistics/remote |
| WorkMarket middleman rate shaving | Transparent rate display; partner-of-record clarity |
| Barrister predatory post-deploy cuts | Absolute compensation in work order contract |
| Hours on hold for support | **Leta Live** routes to project pod, not generic offshore queue |

## Fairness protocols

- **Two-hour minimums** on technical dispatches (where policy applies)
- **Per-mile travel** embedded in work order terms
- **No punitive cancel matrices** when remote/logistics caused abort

## Philosophy

The field technician is the physical embodiment of the platform; **tech NPS correlates with customer success**.
