# Autonomous algorithmic dispatch

Human-led dispatch—whiteboards, siloed schedulers, frantic phone calls—is a profound bottleneck. Open marketplaces worsen this by forcing buyers to manually sift hundreds of unvetted bids.

Leta deploys an **AI-driven routing and auto-dispatch engine**, elevating human dispatchers to **exception monitors** rather than assigners.

## Optimization matrix (per incoming work order)

Evaluated in sub-second time:

1. **Geospatial & temporal proximity** — live traffic, closures, historical transit times.
2. **Skill matrix matching** — OEM certs, historical success on identical hardware, clearances.
3. **SLA hierarchy** — mission-critical server failure prioritized over routine PM.
4. **Vehicle inventory validation** — required parts present in tech's tracked van stock.

## Dynamic re-optimization

If a tech is delayed on a complex job, or an emergency ticket arrives, the engine **recalculates the regional board**—reassigning lower-priority work and routing the nearest qualified tech to the emergency **without phone trees**.
