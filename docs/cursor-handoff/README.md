# Cursor chat handoffs (portable)

Markdown backups of important Cursor sessions live here so you can continue on **another machine** (e.g. Ubuntu laptop) without relying on synced chat history.

## How to use on Ubuntu Cursor

1. `git pull` on the `leta` repo.
2. Open the handoff file (newest date first).
3. In Cursor chat, type **`@`** and select the handoff file, then ask e.g.  
   *“Continue from this handoff — install OpenClaw on this Ubuntu box.”*

Chat history does **not** sync between Mac and Ubuntu; this folder is the bridge.
